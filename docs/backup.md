# Мэдээллийн сангийн нөөц хуулбар

GitHub Actions долоо хоног бүр (Даваа 02:00, Улаанбаатар) мэдээллийн сангийн бүтэн хуулбар авч, AES256-аар шифрлээд 90 хоног хадгална. Ингэснээр сүүлийн 3 сарын ~13 хуулбар үргэлж бэлэн байна.

## Нэг удаагийн тохиргоо

GitHub → репо → **Settings → Secrets and variables → Actions → New repository secret**:

| Нэр | Утга |
|---|---|
| `DATABASE_URL` | Neon-ий холболтын хаяг (Render дээрх `DATABASE_URL`-тэй ижил) |
| `BACKUP_PASSPHRASE` | Урт санамсаргүй нууц үг. **Үүнийг гээвэл нөөцийг нээж чадахгүй**, нууц үгийн менежерт хадгална |

Санамсаргүй нууц үг үүсгэх: `openssl rand -base64 32`

Тохируулсны дараа **Actions → DB backup → Run workflow** дарж нэг удаа шууд туршина.

## Нөөцөөс сэргээх

1. **Actions → DB backup** → сүүлийн амжилттай ажиллагаа → **Artifacts**-аас файлыг татна (zip дотор `car-saas-YYYY-MM-DD.sql.gz.gpg`).
2. Шифрийг тайлж, шинэ (эсвэл хоосон) мэдээллийн сан руу сэргээнэ:

```bash
gpg --decrypt car-saas-2026-11-02.sql.gz.gpg | gunzip > backup.sql
psql "postgresql://...ШИНЭ_САНГИЙН_ХАЯГ..." -f backup.sql
```

Анхааруулга: ажиллаж буй production сан руу шууд сэргээвэл одоогийн өгөгдөлтэй давхцана. Эхлээд Neon дээр шинэ branch/сан үүсгээд сэргээж, шалгасны дараа Render-ийн `DATABASE_URL`-ийг солино.
